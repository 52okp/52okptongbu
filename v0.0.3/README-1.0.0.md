# 文章同步工作台 v1.0.0

源码沿用 v0.0.3 目录，应用版本为 1.0.0。

- 本地文章独立保存、编辑和删除，原 HTML 文件删除后仍可使用已导入的正文；在线图片不离线备份。
- 发布计划独立窗口，填写头条时间，其他平台自动计算 72 小时后时间；手动标记已发布。
- 支持多平台草稿同步；CSDN 使用已登录的后台编辑器，不要求 App Key。
- 百家号和 B站上传静态 WebP 时转换为 PNG。
- Windows 更新打开安装向导，沿用用户保存的数据位置。

推送 main 后，GitHub Actions 分别构建 Windows x64 NSIS 安装包及 macOS Intel x64 DMG / ZIP，并发布到 GitHub Releases。未配置签名和 macOS 公证。
第三方平台接口、账号权限和页面可能变化；同步后请在平台复核草稿。程序不自动公开发布文章。
